# CAPEX / SPORTS — Quant Terminal

A responsive React dashboard for evaluating sports assets, venue economics, and growth capital allocation.

## Highlights

- Portfolio value, IRR, deployed capital, and risk-adjusted score cards
- 12-month portfolio growth visualization
- Allocation mix by asset category
- Searchable asset watchlist with risk bands and signals

## Run locally

```bash
npm install
npm run dev
```

## Stack

React 19 · Vite · Tailwind CSS 4 · Lucide React

> Illustrative product concept. Sample data is not investment advice.
